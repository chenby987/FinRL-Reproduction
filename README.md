## 3. 訓練環境 | Training Environment

| 項目 | 詳細內容 |
|---|---|
| **環境類別** | `StockTradingEnv`（繼承 `gymnasium.Env`） |
| **狀態空間 (State)** | **301 維**：1 (帳戶餘額) + 30 (持股數量) + 30 (股價) + 240 (8 指標 × 30 股) |
| **動作空間 (Action)** | **連續 30 維**：每支股票 [-100, +100]，正值=買入、負值=賣出 |
| **初始資金** | $1,000,000 |
| **每股最大交易量** | 100 股 (hmax=100) |
| **交易手續費** | 買入 0.1% + 賣出 0.1% |
| **獎勵函數 (Reward)** | 資產淨值變化量 × reward_scaling (1e-4) |
| **風控機制** | Turbulence Index > 70 時自動停止交易 |
| **技術指標 (8 個)** | MACD, Bollinger Upper, Bollinger Lower, RSI(30), CCI(30), DX(30), SMA(30), SMA(60) |
| **額外特徵** | VIX 波動率指數, Turbulence Index |
| **DRL 演算法** | A2C, DDPG, PPO, TD3, SAC（共 5 種） |
| **訓練步數** | 50,000 steps per agent |

## 8. 差距原因分析 | Gap Analysis & Discussion

### Sharpe Ratio 差距（0.76 vs 1.30）

| 原因 | 說明 | 影響 |
|---|---|---|
| **未實作 Ensemble** | 論文透過動態切換代理降低波動率、提高風險調整回報。我們僅測試單一代理 | 🔴 主因 |
| **訓練步數較少** | 我們 50,000 步 vs 論文可能 100,000+ 步，代理可能未完全收斂 | 🟡 次因 |
| **隨機種子** | DRL 訓練本身具有隨機性，單次實驗難以代表平均表現 | 🟡 次因 |

### Max Drawdown 差距（26.28% vs 11.52%）

| 原因 | 說明 |
|---|---|
| **COVID-19 崩盤（2020/03）** | 從圖表可見所有代理在 2020 年 3 月大幅回撤，單一代理無法應對極端行情 |
| **Ensemble 的核心價值** | 論文的 Ensemble 策略在崩盤期能切換到更保守的代理（如 Min-Variance），有效控制了回撤至 11.52% |
| **這正是 Ensemble 存在的理由** | 降低 MDD 是 Ensemble 相比單一代理最大的優勢 |

### 報酬率反而更高的原因（+24.80% vs +19.19%）

- DDPG 在 2019 年牛市階段激進做多，取得了更高的絕對報酬
- 但高報酬伴隨高回撤（MDD 26.28%），風險調整後表現（Sharpe）不如 Ensemble
- Ensemble 犧牲了一部分報酬率，換取更穩定的表現（高 Sharpe、低 MDD）

## 9. 改善方向 | Proposed Improvement

| 優先級 | 改善方向 | 具體做法 | 預期效果 |
|---|---|---|---|
| 🔴 **最高** | 實作 Ensemble 策略 | 每 3 個月根據 validation Sharpe 切換最佳代理 | 預期 MDD 降至 ~12%，Sharpe 提升至 ~1.0+ |
| 🔴 高 | 增加訓練步數 | `total_timesteps` → 100,000 ~ 200,000 | 策略更穩定，減少欠訓練問題 |
| 🟡 中 | 多次實驗取平均 | 不同隨機種子跑 5~10 次 | 結果更具統計意義 |
| 🟡 中 | 超參數調優 | 使用 Optuna 做 Bayesian Optimization | 找到更優的參數組合 |
| 🟢 低 | 加入更多特徵 | 新聞情緒、基本面數據、宏觀經濟指標 | 更豐富的狀態表示 |

## 13. 備註/心得 | Notes / Reflection

### 環境搭建

- Python 版本**必須**用 3.10（3.12+ 會導致 cvxpy 編譯失敗）
- `TA-Lib` 必須從 conda-forge 安裝，pip 安裝會缺少 C 庫
- 系統需預先安裝 `cmake`、`swig`（可用 conda 替代 apt）
- `gym` 已棄用的警告雖然無害但很煩，框架應遷移到 `gymnasium`

### DRL 交易策略的理解

- **DRL 不是預測股價，而是學習交易行為**：代理學到的是「什麼時候買、什麼時候賣」，而非「明天會漲還是跌」
- **絕對報酬不代表策略好壞**：關鍵在於**超額報酬**（相對大盤賺多少）
- **單一代理有市場偏好**：DDPG 擅長牛市、TD3 擅長熊市，這正是 Ensemble 存在的意義
- **訓練的隨機性很大**：同一演算法、同一參數，不同隨機種子的結果可能差距不小

### 核心結論

> 1. **重現成功**：DDPG 在原論文交易期取得 +24.80% 報酬，超越論文 Ensemble 的 +19.19%
> 2. **泛化驗證**：跨資料集（2026 熊市）中 TD3/A2C 仍超越 DJIA，DRL 策略具備一定泛化能力
> 3. **Ensemble 是關鍵**：Sharpe 和 MDD 的差距來自未實作 Ensemble，這是後續最值得改進的方向
> 4. **市場環境決定一切**：同樣的程式碼在牛市獲利 +24.80%、在熊市虧損 -2.76%，DRL 不是萬能的
